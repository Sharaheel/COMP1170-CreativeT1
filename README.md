# Alien Campsite

A stylized low-poly alien campsite environment created in Blender and later assembled in Unreal Engine 5.7.

The project started as a more traditional caravan campsite and gradually evolved into a colourful alien/fantasy environment with exaggerated shapes, vibrant colours, and a low-poly art style.

## Project

The environment includes:

- Stylized caravan
- Campsite props
- Trees and alien vegetation
- Grass variations
- Rock formations
- Low-poly terrain
- River
- Custom colour/gradient texture atlas

All 3D models and environment assets were created from scratch in Blender.

## Tools

- Blender 4.5
- Unreal Engine 5.7
- GIMP
- PureRef

## Repository

This repository is mainly used for source control and keeping track of the Blender project throughout development.

The commit history contains different stages and iterations of the environment as it developed from the initial models into the final asset set.

## Final Environment

The Blender assets were exported to Unreal Engine, where the final environment was assembled with foliage placement, collision, player navigation, and the completed scene layout.
